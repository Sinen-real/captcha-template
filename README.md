# 验证码 P图模板生成器

**在线使用：https://sinen-real.github.io/mock-captcha/**

仿 reCAPTCHA 风格的验证码截图生成器，做素材、样机图用。全程在浏览器里跑，
上传的图片不会离开本机；调完参数直接导出 PNG。

## 三种模式

### 图片验证码
把一张图切成 3×3 / 4×4 的宫格，指定哪几格是「正解」，改标题与提示文案、顶栏背景、
选中角标、底部图标和验证按钮。支持整图切分、每格单图、双图叠选三种上传方式，
可以打乱切块顺序，也可以开点按凹入的动效。

### 文字验证码
目标字一部分在顶栏（花字），一部分散在图里。字能手动拖位置，能按空格切成词组，
能加「只在图里出现」的额外字、和「只在顶栏出现」的隐藏目标字。每个字带随机字效，
顶栏与图里两组的歪斜角度各自独立，范围最大 ±180°。

### 拼图验证码
缺口与拼图块共用一套形状：拼图 / 方形 / 圆形 / 三角 / 五角星，或上传一张自己的形状图
（透明底、白底都行，阈值可调；缺口与拼图块也可以各用一张）。两边能各自旋转、调颜色，
对齐或故意错开。滑块、轨道、图标、标题提示都能换，预览里可以直接拖拼图块和缺口。

## 其他

- 「我不是机器人」前置动效，三种模式都能挂在预览前（只做演示，不进导出）
- 标题、提示、按钮文字都是富文本，可局部加粗 / 改字号 / 改颜色
- 整页按手机竖屏排版，电脑上也是同一个版式
- 「还原」会先弹一次确认

本地双击 `captcha.html` 也能直接用。
